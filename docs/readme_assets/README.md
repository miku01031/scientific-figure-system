# README atlas assets

These are high-resolution, public-safe overview sheets assembled from the project's own synthetic benchmark outputs. They are display assets for the bilingual README; they are not scientific evidence and do not expand the tested renderer scope.

| Asset | Source overview | Transformation |
|---|---|---|
| `chart_archetype_atlas.png` | Scientific Chart Archetype Atlas master | Byte-identical copy |
| `chart_archetype_atlas_families_1.png` | Chart Atlas Families A–C | Lossless vertical stack of the original family sheets |
| `chart_archetype_atlas_families_2.png` | Chart Atlas Families D–F | Lossless vertical stack of the original family sheets |
| `chart_archetype_atlas_families_3.png` | Chart Atlas Families G–I | Lossless vertical stack of the original family sheets |
| `schematic_quality_overview.png` | Final Quality Acceptance schematic sheet | Byte-identical copy |
| `flowchart_grammar_overview.png` | Flowchart Grammar Atlas B1–B8 sheet | Byte-identical copy |
| `flowchart_grammar_overview_1.png` | Flowchart Grammar Atlas B1–B4 | Lossless crop for readable detail |
| `flowchart_grammar_overview_2.png` | Flowchart Grammar Atlas B5–B8 | Lossless crop for readable detail |

The chart atlas, schematic sheet, and flowchart sheets are synthetic demonstrations generated by this project's own benchmark renderers. They contain no paper screenshots, reference-paper artwork, real research data, or third-party assets. The family sheets and flowchart detail sheets only arrange or crop existing content; no scientific geometry, values, labels, connectors, or colors were edited. `README_PREVIEW_ASSET_MANIFEST.json` records source identifiers and SHA-256 hashes without publishing private filesystem paths.

The obsolete small `hero_preview.png`, `figure_gallery.png`, and `schematic_gallery.png` previews were removed so the README can present the high-resolution overviews directly. The assets can be regenerated only from the corresponding synthetic benchmark packages in a separately authorized staging directory; no README build is required for core CI.
